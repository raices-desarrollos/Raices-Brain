# Proveedores

Este directorio organiza la red de proveedores y profesionales que trabajan con Raíces Desarrollos.

## Estructura

| Carpeta               | Tipo de proveedor                             |
| --------------------- | --------------------------------------------- |
| `architects/`         | Estudios de arquitectura y directores de obra |
| `contractors/`        | Constructoras y empresas de obra              |
| `renderers/`          | Estudios de renders y visualización 3D        |
| `surveyors/`          | Agrimensores y estudios de medición           |
| `notaries/`           | Escribanías y notarías                        |
| `accountants/`        | Contadores y asesores fiscales                |
| `real-estate-agents/` | Inmobiliarias y brokers                       |

## Cómo documentar un proveedor

Crear un archivo Markdown con el nombre del proveedor en la carpeta correspondiente. Incluir:

- Nombre y datos de contacto
- Proyectos en los que trabajó con Raíces
- Evaluación de desempeño
- Condiciones comerciales generales
- Observaciones
