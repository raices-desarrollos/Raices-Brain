# Criterios de Evaluación de Terrenos — Raíces Desarrollos

Define qué hace que un terreno sea elegible para un proyecto de Raíces Desarrollos.

## Criterios eliminatorios (si no se cumple, se descarta)

| Criterio           | Mínimo                                                        |
| ------------------ | ------------------------------------------------------------- |
| Zonificación       | Debe permitir uso residencial                                 |
| FOT aprovechable   | > 1.5 (o equivalent según normativa local)                    |
| Superficie mínima  | > 150 m² de frente                                            |
| Situación dominial | Sin litigios, sucesiones sin resolver o hipotecas complicadas |
| Acceso vehicular   | Posible desde la calle (para garage)                          |

## Criterios de puntaje (0 a 10 por criterio)

| Criterio                                | Peso | Descripción                             |
| --------------------------------------- | ---- | --------------------------------------- |
| Ubicación y demanda de compradores      | 25%  | ¿Hay demanda real en la zona?           |
| Potencial constructivo (m² vendibles)   | 20%  | Volumen de negocio posible              |
| Precio del terreno vs. valor de mercado | 20%  | ¿Está en precio o caro?                 |
| Calidad de la calle y el entorno        | 15%  | Arbolado, estado edilicio, tráfico      |
| Accesibilidad y transporte              | 10%  | Distancia a subte, bus, comercios       |
| Riesgos especiales                      | 10%  | Medianeras altas, servidumbres, retiros |

## Puntaje mínimo para avanzar

**60 puntos sobre 100** para pasar de pipeline a análisis profundo.
