## Estructura del directorio

| Carpeta            | Contenido                                                            |
| ------------------ | -------------------------------------------------------------------- |
| `brief/`           | Briefings de proyecto, comercial, arquitectónico y de marca          |
| `architecture/`    | Planos, tipologías, lógica de planta baja, terraza y fachada         |
| `visual-identity/` | Especificaciones de render, paleta de materiales, criterios          |
| `renders/`         | Renders aprobados, exploraciones, referencias y outputs              |
| `financials/`      | Supuestos de costos, presupuesto, rentabilidad y cronograma de pagos |
| `legal/`           | Títulos, escribanía, permisos y contratos                            |
| `commercial/`      | Copy de brochure, web, resumen para inversores y FAQ de compradores  |
| `decisions/`       | Log de decisiones del proyecto con fecha y contexto                  |
| `prompts/`         | Prompts específicos para generación de renders de este proyecto      |
| `meetings/`        | Minutas de reuniones                                                 |
| `tasks/`           | Tareas pendientes y en curso                                         |
| `risks/`           | Registro de riesgos identificados                                    |

PDFs operativos (legales, presupuestos de terceros, brochures de obra) viven en **Google Drive**. No duplicarlos acá; el espejo local es `knowledge/sync-drive/` (fuera de Git).
