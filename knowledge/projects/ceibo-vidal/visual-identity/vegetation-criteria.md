# Criterios de Vegetación — Ceibo Vidal

Define las especies y el criterio de paisajismo para la planta baja y la terraza del proyecto.

## Principio

La vegetación de Ceibo Vidal no es decorativa genérica. Debe evocar el nombre del proyecto, integrarse a la escala peatonal y verse natural y madura, no recién plantada.

## Especies recomendadas

### Planta baja (frente y lateral)

| Especie                                         | Tipo         | Características                                |
| ----------------------------------------------- | ------------ | ---------------------------------------------- |
| Ceibo (_Erythrina crista-galli_)                | Árbol        | Flor roja, árbol nacional, nombre del proyecto |
| Jazmín del Cabo (_Trachelospermum jasminoides_) | Trepadora    | Para muros, fragante, perenne                  |
| Lavanda (_Lavandula angustifolia_)              | Arbusto bajo | Olor, textura, contraste                       |
| Gramineas naturales                             | Herbácea     | Movimiento, textura, mantenimiento bajo        |

### Terraza (piso 5)

| Especie            | Tipo          | Observaciones                             |
| ------------------ | ------------- | ----------------------------------------- |
| Olivo en maceta    | Árbol pequeño | Resistente, estético, bajo mantenimiento  |
| Lavanda            | Arbusto bajo  | Mismo criterio que PB, unidad visual      |
| Hierbas aromáticas | Herbácea      | Uso posible en cocina, criterio funcional |

## Criterio visual para renders

- Vegetación madura, no recién plantada ni demasiado perfecta.
- Movimiento implícito: como si hubiera una leve brisa.
- Verde con variedad de tonos, no monocromático.
- Las plantas nunca tapan los balcones ni la lectura de la fachada.
