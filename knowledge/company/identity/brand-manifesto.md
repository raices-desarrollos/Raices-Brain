# Manifiesto de Marca — Raíces Desarrollos

Este documento define la esencia de la marca Raíces: quiénes somos, qué creemos y cómo queremos ser percibidos.

## Quiénes somos

Raíces Desarrollos es una desarrolladora inmobiliaria argentina que construye edificios con identidad. No hacemos metros cuadrados: creamos lugares donde las personas quieren vivir.

## Lo que creemos

- La arquitectura de calidad no debería ser un lujo reservado para pocos.
- Cada proyecto debe tener una narrativa propia, una razón de existir.
- La transparencia con inversores y compradores es la base de cualquier relación duradera.
- El detalle importa: en la fachada, en el contrato, en el correo de bienvenida.

## Lo que nos diferencia

- Pensamos cada proyecto desde la identidad visual antes que desde la obra.
- Integramos IA en nuestros procesos internos para tomar mejores decisiones más rápido.
- Documentamos todo: cada decisión tiene contexto, fecha y alternativas consideradas.

## Nuestra promesa

> Raíces construye edificios que tienen historia antes de inaugurarse.

## Valores de marca

| Valor             | Descripción                                               |
| ----------------- | --------------------------------------------------------- |
| **Autenticidad**  | Cada proyecto tiene una identidad genuina, no una fórmula |
| **Precisión**     | Los detalles definen la diferencia                        |
| **Transparencia** | Con inversores, compradores y el equipo                   |
| **Ambición**      | Apuntamos a lo mejor dentro de cada escala                |
| **Arraigo**       | Construimos en barrios que entendemos y respetamos        |
