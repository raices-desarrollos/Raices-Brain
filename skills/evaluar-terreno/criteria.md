# Criterios de evaluación — Skill evaluar-terreno

Ver la versión completa en `knowledge/terrains/criteria.md`.

## Resumen rápido para la skill

| Criterio               | Peso | Pregunta clave                              |
| ---------------------- | ---- | ------------------------------------------- |
| Ubicación y demanda    | 25%  | ¿Hay compradores en esta zona?              |
| Potencial constructivo | 20%  | ¿Cuántos m² vendibles puedo hacer?          |
| Precio vs. mercado     | 20%  | ¿Está en precio justo o caro?               |
| Calidad del entorno    | 15%  | ¿Es una calle donde la gente quiere vivir?  |
| Accesibilidad          | 10%  | ¿Llego fácil sin auto?                      |
| Riesgos especiales     | 10%  | ¿Hay algo que complique la obra o la venta? |

**Umbral para avanzar:** 60/100 puntos ponderados.
