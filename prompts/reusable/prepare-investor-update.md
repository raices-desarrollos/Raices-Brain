# Prompt: Preparar actualización para socios/inversores

**Uso:** Generar un update periódico para socios e inversores de un proyecto.

## Prompt

```
Generá una actualización ejecutiva para socios e inversores del proyecto [nombre del proyecto].

Período: [Mes/Trimestre y año]

Secciones requeridas:

1. **Estado general del proyecto** (1 párrafo, tono directo y positivo pero honesto).
2. **Hitos alcanzados en el período** (lista con fechas).
3. **Estado financiero resumido** (tabla simple: presupuesto vs. real si hay datos).
4. **Próximos hitos** (los 3 más importantes con fecha estimada).
5. **Alertas o puntos de atención** (si hay algún riesgo o retraso, mencionarlo con contexto).
6. **Acción requerida del socio/inversor** (si aplica: firma, pago de cuota, decisión pendiente).

Tono: Directo, transparente, profesional. Sin lenguaje corporativo vacío. Si algo está retrasado, decirlo claramente con contexto.

DATOS DEL PERÍODO:
[Pegar los datos, notas o contexto del período aquí]
```

## Instrucciones de uso

1. Completar con los datos reales del período.
2. El update generado debe revisarse y aprobarse por el equipo antes de enviar.
3. Guardar en `knowledge/company/commercial/investor-materials/` con formato `YYYY-MM-[proyecto]-update.md`.

## Notas

- Ver skill `skills/preparar-reporte-socios/` para el proceso completo.
- Nunca enviar sin revisión humana.
