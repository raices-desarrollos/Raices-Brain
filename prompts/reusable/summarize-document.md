# Prompt: Resumir documento

**Uso:** Resumir cualquier documento interno de Raíces en un formato estandarizado.

## Prompt

```
Resumí el siguiente documento en tres secciones:

1. **En una línea:** Una sola oración que capture la esencia del documento.
2. **Puntos clave:** Lista de 3 a 5 puntos principales.
3. **Próximos pasos o pendientes:** Si el documento menciona tareas, decisiones pendientes o próximos pasos, listarlos.

Usá lenguaje claro y directo. No usés jerga ni relleno.

DOCUMENTO:
[Pegar el contenido del documento aquí]
```

## Instrucciones de uso

1. Reemplazar `[Pegar el contenido del documento aquí]` con el texto a resumir.
2. Para documentos muy largos, dividirlos en secciones y resumir cada una por separado.
3. El resumen generado puede guardarse como nota en el directorio correspondiente del proyecto.

## Notas

- Funciona bien para minutas de reunión, briefings, contratos (resumen general) y reports.
- Para documentos financieros, usar el agente `finanzas` en lugar de este prompt.
