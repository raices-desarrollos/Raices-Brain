# Prompt específico: Copy del sitio web — Ceibo Vidal

**Proyecto:** Ceibo Vidal  
**Uso:** Generación y refinamiento del copy del sitio web.

## Prompt base

```
Generá el copy completo del sitio web de Ceibo Vidal, un edificio residencial en Buenos Aires desarrollado por Raíces Desarrollos.

Características del edificio:
- PB + 4 pisos + terraza
- Cuatro balcones visibles al frente (uno por piso)
- Terraza exclusiva en el último piso
- Garage integrado en planta baja
- [Placeholder: agregar barrio, tipologías y precios cuando estén disponibles]

Secciones a generar:
1. Hero (headline + subheadline + CTA)
2. Descripción del edificio (1-2 párrafos)
3. Tipologías (descripción breve de cada tipología)
4. Por qué Ceibo Vidal (3-4 argumentos clave)
5. Sobre Raíces Desarrollos (2-3 líneas)
6. CTA final

Tono: Directo, concreto, sin superlativos vacíos. Siguiendo el tono de voz de Raíces Desarrollos.

Target: Compradores finales de primera o segunda vivienda, 30-45 años, Buenos Aires.
```

## Instrucciones de uso

1. Completar los placeholders antes de usar.
2. El copy generado va a `knowledge/projects/ceibo-vidal/commercial/website-copy.md`.
3. Revisar con el agente `comercial` para ajustar tono si es necesario.

## Notas

- Ver `brief/commercial-brief.md` para los mensajes clave del proyecto.
- El copy de web debe ser consistente con el brochure y los materiales de Instagram.
