# Prompt específico: Investor deck — Ceibo Vidal

**Proyecto:** Ceibo Vidal  
**Uso:** Generación de contenido para el deck de presentación a inversores.

## Prompt base

```
Generá el contenido de texto para un investor deck de Ceibo Vidal, un proyecto inmobiliario residencial en Buenos Aires desarrollado por Raíces Desarrollos.

Slides a generar:
1. Portada: nombre del proyecto, tagline, logo placeholder
2. La oportunidad: contexto del mercado y la zona
3. El producto: descripción del edificio y sus diferenciales
4. Tipologías y precios: tabla de unidades
5. El equipo: Raíces Desarrollos y sus valores
6. Los números: resumen financiero (TIR, margen, plazo)
7. Estructura de inversión: cómo se invierte, cómo se cobra
8. Próximos pasos: proceso para unirse al proyecto
9. Contacto

Tono: Profesional, directo, honesto. Sin lenguaje de marketing exagerado. Los inversores valoran los números claros y los riesgos reconocidos.

DATOS A COMPLETAR:
- Barrio: [Placeholder]
- Tipologías y precios: [Placeholder]
- TIR proyectada: [Placeholder]
- Estructura de inversión: [Placeholder]
```

## Instrucciones de uso

1. Completar todos los placeholders con datos reales antes de usar.
2. El contenido generado complementa (no reemplaza) el trabajo de diseño del deck.
3. Revisar con el agente `finanzas` para validar los números antes de presentar.
4. Revisión legal obligatoria antes de compartir con inversores.

## Notas

- Ver `commercial/investor-summary.md` para la versión de una página.
- El deck completo debe ser revisado por el equipo antes de cualquier uso externo.
