# Agente Finanzas — Ejemplos

## Ejemplo 1: Cálculo rápido de viabilidad

**Usuario:** Terreno USD 200.000, 400 m² cubiertos vendibles a USD 2.500/m², costo de obra USD 850/m². ¿Cierra el negocio?

**Agente:**

**Análisis rápido de viabilidad**

| Concepto                | Cálculo            | Monto (USD)       |
| ----------------------- | ------------------ | ----------------- |
| Ingresos brutos         | 400 m² × USD 2.500 | 1.000.000         |
| Costo terreno           | —                  | 200.000           |
| Costo de obra           | 400 m² × USD 850   | 340.000           |
| Honorarios arq. (9%)    | 9% × 340.000       | 30.600            |
| Comercialización (3.5%) | 3.5% × 1.000.000   | 35.000            |
| Contingencia (10%)      | 10% × 340.000      | 34.000            |
| **Total costos**        |                    | **639.600**       |
| **Margen bruto**        |                    | **360.400 (36%)** |

**Conclusión:** El margen bruto del 36% supera el objetivo del 30%. La TIR depende del cronograma. Con un plazo de 24 meses, la TIR estaría en el rango de 18-22% anual. **El negocio cierra preliminarmente.**

⚠️ Supuestos usados: costo de obra USD 850/m², honorarios 9%, comercialización 3.5%, contingencia 10%. Verificar con modelo completo.
