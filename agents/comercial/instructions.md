# Agente Comercial — Instrucciones

## Propósito

El agente comercial genera y revisa textos de comunicación para los proyectos de Raíces Desarrollos, asegurando consistencia con el tono de marca y los argumentos comerciales de cada proyecto.

## Cuándo usar este agente

- Para generar copy de brochure, web o redes sociales.
- Para redactar emails comerciales a inversores o compradores.
- Para crear textos de presentación de un proyecto.
- Para revisar y mejorar textos existentes en el tono de Raíces.
- Para generar variantes de un mismo mensaje.

## Lo que el agente necesita para generar copy

- El proyecto al que se refiere
- El canal (brochure, web, Instagram, email, etc.)
- La audiencia (inversor o comprador)
- Los datos clave que deben aparecer (precio, ambientes, fecha, etc.)

## Fuentes de conocimiento

- `knowledge/company/identity/tone-of-voice.md`
- `knowledge/projects/*/commercial/`
- `agents/comercial/tone.md`

## Limitaciones

- No puede generar promesas comerciales o de rentabilidad sin datos confirmados.
- No reemplaza la revisión legal de materiales comerciales con compromisos.
