# Rúbrica de Evaluación de Terrenos — Agente Terrenos

Criterios detallados para puntuar cada dimensión de la evaluación.

## Criterio 1: Ubicación y demanda de compradores (25%)

| Puntaje | Descripción                                                                     |
| ------- | ------------------------------------------------------------------------------- |
| 9-10    | Zona con demanda probada de compradores finales, precio de venta alto y estable |
| 7-8     | Zona con buena demanda, precio de venta competitivo                             |
| 5-6     | Zona con demanda moderada o en crecimiento                                      |
| 3-4     | Zona con demanda baja o incierta                                                |
| 0-2     | Zona sin demanda de compradores finales identificada                            |

## Criterio 2: Potencial constructivo (20%)

| Puntaje | Descripción                       |
| ------- | --------------------------------- |
| 9-10    | > 1.000 m² vendibles, FOT > 2     |
| 7-8     | 600-1.000 m² vendibles            |
| 5-6     | 400-600 m² vendibles              |
| 3-4     | 200-400 m² vendibles              |
| 0-2     | < 200 m² vendibles o FOT muy bajo |

## Criterio 3: Precio vs. mercado (20%)

| Puntaje | Descripción                                            |
| ------- | ------------------------------------------------------ |
| 9-10    | Precio muy por debajo del valor de mercado del terreno |
| 7-8     | Precio en línea o ligeramente por debajo del mercado   |
| 5-6     | Precio justo de mercado                                |
| 3-4     | Precio ligeramente por encima del mercado              |
| 0-2     | Precio significativamente por encima del mercado       |

## Criterio 4: Calidad del entorno (15%)

| Puntaje | Descripción                                                  |
| ------- | ------------------------------------------------------------ |
| 9-10    | Calle arbolada, entorno edilicio cuidado, mixtura positiva   |
| 7-8     | Entorno bueno con algunos puntos de mejora                   |
| 5-6     | Entorno neutro, ni impulsa ni frena el proyecto              |
| 3-4     | Entorno con problemas visibles (deterioro, vacíos, ruido)    |
| 0-2     | Entorno significativamente negativo para la comercialización |

## Criterio 5: Accesibilidad (10%)

| Puntaje | Descripción                                                  |
| ------- | ------------------------------------------------------------ |
| 9-10    | A < 500 m de subte o metrobús, alto puntaje de caminabilidad |
| 7-8     | A < 1 km de transporte relevante, buena conectividad         |
| 5-6     | Conectividad media, varias opciones de transporte            |
| 3-4     | Dependencia de auto o un único medio de transporte           |
| 0-2     | Mala accesibilidad, zona aislada                             |

## Criterio 6: Riesgos especiales (10%)

| Puntaje | Descripción                                                            |
| ------- | ---------------------------------------------------------------------- |
| 9-10    | Sin riesgos especiales identificados                                   |
| 7-8     | Algún riesgo menor manejable                                           |
| 5-6     | Un riesgo importante pero con solución viable                          |
| 3-4     | Múltiples riesgos o uno muy significativo                              |
| 0-2     | Riesgos graves (medianeras problemáticas, servidumbres, inundabilidad) |
