# Agente Terrenos — Ejemplos

## Ejemplo 1: Evaluación con datos completos

**Usuario:** Tengo un terreno en Almagro, Medrano 700. 200 m², frente 10 m, fondo 20 m. Precio pedido USD 180.000. Zonificación R2b. Entorno residencial, a 3 cuadras del subte B.

**Agente:**

**Evaluación preliminar — Medrano 700, Almagro**

| Criterio                     | Puntaje | Observación                                            |
| ---------------------------- | ------- | ------------------------------------------------------ |
| Ubicación y demanda (25%)    | 8/10    | Almagro tiene demanda sostenida de compradores finales |
| Potencial constructivo (20%) | 6/10    | R2b con FOT ~2.4 → ~480 m² cubiertos. Escala pequeña   |
| Precio vs. mercado (20%)     | 7/10    | USD 900/m² para Almagro parece razonable, verificar    |
| Calidad del entorno (15%)    | 7/10    | Almagro bien consolidado, calle arbolada               |
| Accesibilidad (10%)          | 9/10    | A 3 cuadras del subte B, excelente                     |
| Riesgos especiales (10%)     | 7/10    | Verificar medianeras y situación dominial              |

**Puntaje ponderado: 74/100** → Supera el mínimo de 60.

**Puntos fuertes:**

1. Excelente accesibilidad (subte a 3 cuadras)
2. Zona con demanda probada
3. Precio aparentemente razonable

**Riesgos:**

1. Escala pequeña (~480 m²) — revisar si justifica la operación
2. FOT R2b a confirmar con normativa vigente
3. Situación dominial no verificada

**Recomendación: Avanzar al siguiente paso** — verificar normativa y situación dominial antes de hacer oferta.
